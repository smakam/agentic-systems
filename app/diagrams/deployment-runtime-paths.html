Marketplace runtime and deployment architecture

Three logical components. Choose the agent runtime in chat; configure its business backend separately.

Normal recording: local demo

Chat and business data stay on the laptop. SDK executes locally; Google and Lyzr remain hosted and use the laptop MCP tunnel.

Later walkthrough: cloud demo

Chat and business data run on GCP. Configure each runtime to the cloud business backend before changing runtimes in chat.
