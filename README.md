# Inside AI Agent Systems: From Components to Platforms

A synthetic marketplace support application for learning agent systems. Configure a capability, run a business scenario, inspect its evidence, and compare the result.

## Start here

1. Follow [Local Setup](app/LOCAL-SETUP.md), the main lab path. It covers prerequisites, private provider credentials, startup, checks and shutdown. Mac is the primary path; platform differences are documented.
2. Read the [application guide](app/README.md) and try the [first-agent exercise](course/exercises/first-agent/exercise.md).
3. Choose another lab from the [exercise index](course/exercises/README.md). Each package includes practice and separate answers.
4. Use [Cloud Setup](app/CLOUD-SETUP.md) for the optional cloud path. Provision only your own lab resources and follow its cleanup instructions.

[Architecture](SPECIFICATION.md) · [Contribution guide](course/CONTRIBUTING.md) · [Evaluation](app/eval/README.md)

## What is included

Application source, dependency manifests and locks, tests, synthetic seed data, deployment scripts, diagrams, setup guides and exercises are versioned here. Recordings, slide PDFs, instructor planning, course checklists, credentials, Terraform state, dependencies and generated run outputs are maintained separately.

Use your own API keys and accounts. This is a teaching lab with synthetic data; demonstration scores and bounded setup checks do not establish production readiness or validation of every operating system, provider and fresh-account path.
