# Contributing

Contributions to the Marketplace Support Lab are welcome. You can use and extend this application independently of the course.

1. Fork the repository and create a focused branch.
2. Implement one useful agentic capability or configurable experiment, and explain the intended behavior.
3. Review the diff, validate the result, and exclude credentials, private data, dependencies and generated outputs.
4. Open a pull request against `smakam/agentic-systems:main` with the change, rationale, validation and any limits.
5. Respond to maintainer feedback. Changes enter the shared repository only after review and merge; merging does not automatically deploy a service.

Read the [detailed contribution guide and worked example](course/CONTRIBUTING.md) for scope, commands, validation, review and how to update your copy after a merge.

Please submit only material you have the right to contribute and intend to make available under this repository's [MIT License](LICENSE). Do not include provider keys, private `.env` files, Terraform state or private user data in a pull request.
